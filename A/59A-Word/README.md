# Codeforces 59A - Word

## Problem

Given a word containing uppercase and lowercase letters, convert the
whole word to either uppercase or lowercase.

- If uppercase letters are more than lowercase letters, convert to uppercase.
- Otherwise, convert to lowercase.
- If both counts are equal, convert to lowercase.

## Approach

1. Count uppercase letters.
2. Count lowercase letters.
3. Compare the two counts.
4. Print the word in uppercase if uppercase count is greater.
5. Otherwise, print it in lowercase.
