# Codeforces 136A - Presents

## Problem
Given n friends and an array p, where friend i gives a gift to friend p[i], find the giver for each friend.

## Approach
1. Read the array p.
2. For each friend i, store i as the giver of friend p[i].
3. Print the giver array in friend-number order.

## Complexity
- Time: O(n)
- Space: O(n)
