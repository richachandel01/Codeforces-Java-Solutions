# Codeforces 41A - Translation

## Problem

Given two words `s` and `t`, check whether `t` is the reverse of `s`.

## Approach

- Read `s` and `t`.
- Reverse `s` using `StringBuilder`.
- Compare the reversed string with `t`.
- If they are equal, print `YES`.
- Otherwise, print `NO`.
